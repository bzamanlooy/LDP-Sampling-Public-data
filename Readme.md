# Locally Private Sampling with Public Data  
The manuscript is available as Locally_Private_Sampling_with_Public_Data.pdf on this GitHub repository.

## Installation  
Install requirements.
```bash
pip install -r requirements.txt
```  

## Download Datasets  
Extract datasets to the root directory:  

- **Avazu Click-Through Rate:** [Download](https://www.kaggle.com/c/avazu-ctr-prediction/data)  
- **MovieLens 100K:** [Download](https://grouplens.org/datasets/movielens/100k/)  
- **MovieLens 1M:** [Download](https://grouplens.org/datasets/movielens/1m/)  

## Reproducing Figures  
Run Jupyter notebooks:  

- **Figure 2:** `Synthetic.ipynb` 
- **Figure 3:** `Avezu.ipynb`  
- **Figure 4:** `MovieLens.ipynb`
